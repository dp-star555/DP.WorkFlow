# 视觉算子落地与后续路线

不再只是建议。本轮已增加8个节点，完整Module共18节点，实际用法见[已落地算子](vision-operators.md)。相机实机工作按用户安排延期。

## 已实现

| 能力 | 实际实现 |
|---|---|
| 显式预处理 | 灰度、反相、Gaussian、中值、固定增益/偏置、Gray16→Gray8；新FrameId |
| Region分割/形态学 | 灰度闭区间、精确ROI/绑定掩码交集、膨胀/腐蚀/开闭/填孔、三种核、明确零背景边界 |
| Blob特征筛选 | 面积、栅格周长/圆度、面积矩等效椭圆长短轴及方向/轴比；空选集正常 |
| 采样卡尺 | 双线性带采样、剖面、极性、梯度峰抛物线插值、边缘间距抑制；不是Canny改名 |
| 鲁棒直线 | 确定性RANSAC、正交重拟合、内点索引/RMS、退化和预算拒绝 |
| 姿态定位 | 有界离散旋转/尺度搜索、有效模板掩码分数、单个最佳结果、共享定位身份/正反矩阵、显式局部ROI随动及双坐标结果 |
| Workflow闭环 | 强类型配置/输入/输出、能力预检、跨帧拒绝、失败不提交、JSON重跑、原生证据页面、双示例服务装配 |

## 后续能力，不冒充已交付

1. Region独立并/差算子及连通分解节点；当前包含/排除ROI可表达集合范围，绑定掩码可求交，但没有全部独立布尔节点。
2. Blob凸度、孔洞计数、真实亚像素轮廓周长；当前圆度基于栅格单元边界，有方向离散偏差。
3. 卡尺业务边缘配对策略；当前输出所有达标边缘，调用者选择后用距离节点计算宽度。
4. 鲁棒圆/圆弧和角度覆盖判据；当前鲁棒节点只拟合直线。
5. 连续姿态细化、多实例和学习式形状模型；当前定位只搜索明确离散角度/尺度，不保证连续最优。
6. 裁剪/仿射校正图像输出；需要新FrameId、源目标映射、插值/边界和证据回投契约。无需图像重采样的局部ROI随动已落地，见[定位坐标系](vision-coordinate-systems.md)。
7. 颜色空间、白平衡、Lab/ΔE；当前RGB均值不是工业色差。
8. 畸变、相机内参、平面/手眼标定；需真实标定样本、单位、残差和适用范围。
9. 相机长连接、设备目录、触发/重连和吞吐验收，等待现场设备安排。
10. 图像/证据原子存档与侧车文件，显式路径/覆盖规则，无隐式业务目录。

算法持续归属DP.Vision，Workflow只适配领域契约；新增能力应覆盖合成真值、空/退化、精确范围、独立租约、取消/预算及FrameId/坐标一致性。实际工业精度与吞吐仍需现场数据。

不恢复取消的整图OCR、物理切字或无参考打印质量Workflow节点；其他业务使用的独立算法不受影响。
