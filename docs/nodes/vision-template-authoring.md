# 匹配节点挂载的模板制作与资源匹配

本轮实现 OpenCV 模板制作和资源运行闭环；WinForms、WPF 采用同一个制作模型。HALCON 的 NCC/形状算法不在本轮交付范围，当前也没有对应登记项。

## 使用步骤

1. 先保存配方，确定资源保存目录。未保存时仍能读取样图、生成模型和试匹配，应用本地资源会提示先保存配方。
2. 添加“平移模板定位”或“旋转尺度模板定位”，绑定待检测输入图像。
3. 选中匹配节点，在右侧 PropertyGrid 的“模板”分组点击“未选择模板 · 制作/选择…”或“已选择模板 · 查看/修改…”。节点详情窗口中的参数表也提供同一个入口。弹出独立“模板制作/选择”窗口：左侧属性列表，右侧图像与ROI画布。新建、读图、生成模型、测试等按钮均是分组内的属性行，不在列表外另设按钮区。制作、测试和失败原因固定显示在左侧下方，参数滚动不影响状态查看；原“图像与测量范围”仍负责匹配节点搜索区域。
4. 选择匹配实现。现有两项是灰度平方差：固定姿态平移、有界离散旋转尺度。这里没有 NCC 或形状模型，不把平方差分数称为概率。
5. “读取样图”直接读文件；“使用当前输入”复制已有运行输入预览。公共数据图像绑定没有节点预览时，请使用文件读取。
6. 使用页面工具绘制矩形、旋转矩形、椭圆或多边形，可以将区域设为排除。没有区域时使用整张样图；全部有效像素被排除时制作失败。搜索ROI与模板制作ROI使用独立编辑器。
7. 点击“图上设原点”“图上设方向”，然后在样图上点击；也可在“参考坐标”分组编辑原点X/Y和方向角度（°），内部仍保存弧度。图像Y轴向下，正角度为顺时针。坐标单位是参考像素，毫米必须通过明确标定产生。
8. 编辑引擎提供的制作参数，点击“生成模型”。改动制作参数、区域、原点、方向或样图后，需要重新生成。
9. 在“测试设置”选择测试图像，再点击“测试匹配”。默认“模板样图（整图）”适合先验证模型；“当前输入”和“测试图像”沿用本节点搜索范围、父坐标系和掩码。“读取测试图像…”会切换到文件测试来源。阈值和姿态候选可在此修改，确认后随匹配节点保存。缺少同帧坐标/掩码时会报错，不回退整图。测试结果显示检出状态、分数、位置、角度和尺度；未检出与执行失败分别显示。试匹配只更新制作预览，不发布工作流输出或资源。
10. 在模板弹窗点击“确定”或“应用”，发布资源新版本并切换到“资源”模式。若从节点详情的参数表打开，确认只回写父窗口草稿，仍需确认父窗口才修改正式节点。以后运行只需输入图像，不必再放一个读取模板文件的节点。

打开模板弹窗时自动恢复当前已选模板；没有引用时显示空白待制作。在“模板信息”的“已有模板”行选择版本，再点击“读取所选模板”，才恢复该版本；也可使用同组的“刷新模板列表”或“选择模板资源…”按钮导入清单。列表只检查清单，最多列举256个版本，损坏项及缺失/不兼容引擎明确标注，不会静默换引擎。打开通用参数表不扫描资源。读取会恢复样图、区域、参考几何、制作参数及模型快照；完整加载的已有模型可直接测试，无需再次生成。只读取后直接应用会保持原版本；重新生成后应用才发布新版本。

“生成模型”“测试匹配”“应用/确定”按当前条件启用。没有样图、ROI尚未完成、有效区域为空、当前配置没有模型或配方尚未保存时，会显示对应原因；制作或读取期间禁止确认。修改制作条件会清除旧测试并使模型失效，修改测试条件只清除旧测试。有效模型可以在未测试或未检出时保存，测试通过不是强制保存条件。失败原因独立保留，不会被画布刷新覆盖。

“新建空白模板”清空样图、制作区域和参数，并显式建立新的资源身份和输出坐标身份，用于制作另一个模板或替换无法核对的旧资源；旧下游ROI需要重新确认。

## 保存格式与引擎定制

默认引用是配方相对路径：

```text
Resources/Templates/<模板ID>/revisions/<修订ID>/
  manifest.json
  source/image.bin
  source/mask.bin
  source/regions.xml
  variants/opencv-gray/model.bin
```

共同清单记录格式版本、实现ID、模型格式、参考几何、制作参数、文件长度及SHA256。共同样图是有界的中立像素快照；区域XML复用已有带版本的ROI格式。OpenCV模型文件包含裁剪后的Gray8像素、有效掩码、平滑核和角度/尺度制作范围。

引擎通过 IVisionTemplateBuilder 生成自己的相对文件集合，以 ModelFormat 声明格式。文件数量、扩展名、内部格式由引擎决定，不强制厂商采用OpenCV二进制布局。制作入口、参数和显示方式由 IVisionTemplateFactoryDescription 提供；草稿试匹配通过 IVisionTemplatePreviewFactory 返回编辑器独立拥有的资源。

当前每个不可变修订对应一项匹配实现。不同引擎/方法的模型可以保留为同一模板身份下的不同修订，节点引用指定修订；没有“一个修订内任意切换全部引擎”的功能。需要重建的模型使用共同制作依据重新生成，不能把模型文件跨引擎复用。

节点保存资源引用及已确认参考定义。资源路径可以是绝对路径、已保存配方的相对路径或 resource: 引用。携带整个 Resources 目录移动配方后，相对引用继续可用。引擎插件和模板资源分开部署。

## 发布、取消和运行

- 模板制作作为挂载在匹配节点上的独立编辑模型，不是流程中每帧执行的节点。匹配节点保存稳定模板资源ID、指定版本引用及参考定义；制作模型由模板按钮创建隔离草稿，确认后回写。
- 节点窗口和模板弹窗分别使用隔离副本。未应用的制作期间保留内存草稿，直接取消不发布文件、不改正式节点。模板弹窗内点击过“应用”或确认后，再取消父窗口，会保留已发布但未引用的版本；正式节点保持原配置。
- 通用 PropertyGrid 增加 Action 编辑语义，以属性稳定键请求插件页面；共享UI不依赖Vision、HALCON或模型句柄。WinForms/WPF的工作室和节点详情窗口均支持这个入口。
- 通用节点编辑器增加 IWorkflowNodeEditorCommitParticipant，仅在应用时调用页面准备。模板页面先写入同目录草稿，再移动为完整新修订，随后提交节点引用。旧修订不覆盖。
- 写入失败或取消不更新节点引用。资源发布后如果节点提交失败，可能留下未引用版本；不自动删除。撤销/重做恢复引用，不删除其他节点可能使用的资源。本轮没有资源垃圾回收或旧修订删除界面。
- 模型制作及试匹配在后台进行。制作中应用被拒绝，过期完成结果不能覆盖已变化草稿。取消不能强制打断厂商原生调用，资源仍持有到调用结束。
- 打开节点或通用属性投影不读模型。用户点击模板按钮才读取当前资源清单、完整文件快照及样图，不初始化原生匹配模型。显式资源检查可以读取有界清单及文件元数据；真正准备会校验全部内容、格式和原生环境，创建模型。
- 根运行准备还检查节点确认的参考定义。定义不一致时以 ALG_TEMPLATE_REFERENCE_MISMATCH 阻断，发生在采集执行前，位置包含计划、节点和模型槽位。
- 下游节点已保存的ROI参考签名可以与上游资源节点确认的定义进行静态比较；版本或几何不一致在编译时报告，不必等到检测节点执行。
- 同内容、同参考定义和同制作配置的资源可以共享实例，修订路径不同不必重复创建模型。OpenCV声明共享串行，姿态模板缓存上限64MiB；最后租约和调用退出后释放。

## 坐标与兼容

资源模型的参考原点和方向属于样图几何。引擎返回裁剪模板到原图的姿态，共同层组合裁剪偏移与参考定义，生成参考到本帧图像的正反矩阵。节点坐标身份保持稳定，模型内容签名与参考定义签名分开。

同一参考几何只改变制作参数或有效掩码、重新生成模型，不改变坐标语义。改变裁剪范围、原点、方向或样图内容会增加参考版本。替换样图即使尺寸相同也增加版本，要求下游重新确认。新模板的参考资源身份不同，也不能冒充原模板坐标。

匹配未检出时坐标系为空，禁止沿用上一帧矩阵。通用ROI/测量节点通过 IVisionCoordinateResult 绑定资源匹配的 VisionCoordinateSystem。旧 LocateTemplate、LocateTemplatePose 的图像绑定模式及 LocatedCoordinateSystem 签名约束保留；旧配方没有新增字段时仍走原模式。

Vision.MapPoseCoordinate 在资源模式采用共同参考矩阵，(0,0)表示制作时设置的参考原点；旧图像模式保持模板像素边界映射。不能把引擎裁剪模板的(0,0)直接当作新资源的业务原点。

OpenCV资源匹配仍是离散姿态搜索。各候选必须在模型制作角度/尺度范围内，累计比较工作超预算明确报错。平移实现接受一个固定姿态，可以跟随搜索父坐标的旋转/尺度，不接受多个姿态候选。

## 与旧 HALCON 项目的适配关系

旧 HBase_TemplateMatch.Cmd_ChangeTemplateModel 通过按钮调用 HTool_TemplateMatch，按 ModelID 找到独立 HTool_TemplateControl，不存在时创建，再请求展示。当前保留“按钮 → 独立制作模型 → 匹配节点引用”的交互，但使用配方资源身份及隔离草稿，不依赖全局 ToolMge、工具名或静态窗口。

旧代码根据 ShapeBasedMatching/GrayBasedMatching 调用 CreateScaledShapeModel/CreateNccModel，并分别保存 shm/ncm、样图和配置。当前引擎自己的 builder、参数描述、预览工厂和 matcher 是这些能力的接入位置；通用制作窗口不持有 HTuple，也不根据厂商名切换算子。旧 HALCON 文件不能直接当作当前清单导入，HALCON适配器尚未实现。
