# 匹配节点挂载的模板制作与资源匹配

已实现 OpenCV 和 HALCON 模板制作、资源运行闭环；WinForms、WPF 采用同一个制作模型。HALCON通过已有引擎包登记NCC与尺度形状匹配，不新增厂商专用节点或窗口。

## 使用步骤

1. 先保存配方，确定资源保存目录。未保存时仍能读取样图、生成模型和试匹配，应用本地资源会提示先保存配方。
2. 添加“模板定位”，绑定待检测输入图像。只做平移时把角度和尺度区间都设为固定值（默认0°、1倍），此时也可选用只支持平移的模型。
3. 选中匹配节点，在右侧 PropertyGrid 的“模板”分组点击“未选择模板 · 制作/选择…”或“已选择模板 · 查看/修改…”。节点详情窗口中的参数表也提供同一个入口。弹出独立“模板制作/选择”窗口：左侧属性列表，右侧图像与ROI画布。新建、读图、生成模型、测试等按钮均是分组内的属性行，不在列表外另设按钮区。制作、测试和失败原因固定显示在左侧下方，参数滚动不影响状态查看；原“图像与测量范围”仍负责匹配节点搜索区域。
4. 选择匹配实现。OpenCV提供固定姿态平移和离散旋转尺度的灰度平方差；HALCON提供灰度NCC与尺度形状模型。NCC不支持缩放，姿态节点尺度候选须为1；显式设置非1尺度会在能力检查时拒绝NCC，父坐标带入的非1尺度在搜索校验中拒绝。各引擎分数含义不同，阈值分别确认，不视为概率。
5. “读取样图”直接读文件；“使用当前输入”复制已有运行输入预览。公共数据图像绑定没有节点预览时，请使用文件读取。
6. 使用页面工具绘制矩形、旋转矩形、椭圆或多边形，可以将区域设为排除。没有区域时使用整张样图；全部有效像素被排除时制作失败。搜索ROI与模板制作ROI使用独立编辑器。
7. 点击“图上设原点”“图上设方向”，然后在样图上点击；也可在“参考坐标”分组编辑原点X/Y和方向角度（°），内部仍保存弧度。图像Y轴向下，正角度为顺时针。坐标单位是参考像素，毫米必须通过明确标定产生。
8. 编辑引擎提供的制作参数，点击“生成模型”。生成后立即在原制作样图的制作区域外接矩形内，以0°/1倍进行查找，沿用节点阈值和预算。当前制作画面显示绿色匹配框、中心十字和分数；左侧固定显示自检通过、未找到或失败，以及实际图像尺寸、范围、阈值、位置、角度、尺度。自检使用生成的模型调用真实匹配引擎，不以ROI框作为成功证据。生成成功与自检成功是独立状态，自检失败保留模型供排查；不会发布资源或工作流输出。改动制作参数、区域、原点、方向或样图后，需要重新生成，旧自检结果及叠加立即作废。
9. 在“测试设置”选择测试图像，再点击“测试匹配”。默认“制作区域（0°/1倍自检）”只在制作ROI外接矩形中验证模型；它不代替新图像定位测试。“模板样图（整图）”沿用节点角度/尺度搜索区间；“当前输入”和“测试图像”沿用本节点搜索范围、父坐标系和掩码。“读取测试图像…”会切换到文件测试来源。OpenCV预算超限会在测试前显示预计工作量、上限和范围；执行端继续保留同一保护。阈值、预算和搜索上下限可在此修改，确认后随匹配节点保存。缺少同帧坐标/掩码时会报错，不回退整图。测试结果显示检出状态、分数、位置、角度和尺度；未检出与执行失败分别显示。试匹配只更新制作预览，不发布工作流输出或资源。
10. 在模板弹窗点击“确定”或“应用”，发布资源新版本并切换到“资源”模式。若从节点详情的参数表打开，确认只回写父窗口草稿，仍需确认父窗口才修改正式节点。以后运行只需输入图像，不必再放一个读取模板文件的节点。

制作数值参数的上下限随引擎描述传递到属性编辑器。HALCON的“金字塔层数”中0表示自动，合法范围为0至6；在0处减少或在6处增加不会提交越界值。节点算法初始化参数也使用共同的`WorkflowPropertyEntry.WithNumberRange`传递范围，领域写入端仍保留最终校验。非法制作输入提示实际输入值与允许范围；重新提交合法的原值会清除错误提示，不强制重新生成已有效的模型。

制作自检与后续测试图结果独立保留；新图测试未检出不会覆盖制作自检成功。每次读取测试文件都清除上一张图的测试状态，下一次执行才产生新证据。测试状态显示实际搜索条件：制作时允许旋转/缩放，不等于节点会自动使用整个制作范围搜索；姿态节点默认角度上下限均为0°、尺度上下限均为1。旋转或缩放的新图需设置对应搜索区间。制作自检只说明当前模型在原样图上能否找到目标，不能代替新图验收。已有资源只读取时显示尚未制作自检，不凭“模型就绪”伪造检出结果。

模板制作与匹配相关界面统一以度显示，包括模型最小/最大角度、HALCON模型角度步长、运行/测试搜索上下限、OpenCV搜索采样步长、参考方向和检测结果叠加；标定旋转及构建坐标系的固定角度也采用度输入。模型文件、配方字段及算法/坐标计算使用弧度。绑定的角度沿用上游弧度输出，属性面板的固定值做单位转换。

制作范围与运行搜索范围是独立配置，都是相对制作样图的旋转。搜索绑定父坐标时，节点区间相对父坐标：执行时整体加上父旋转、尺度上下限乘以父尺度，再校验模型制作范围。角度区间保留原跨度，跨越±180°时拆成两段，完整360°不会归一化成固定0°。模型制作范围确定可用姿态，修改后须重新生成并应用；在已制作范围内调整运行区间无需重建。制作窗口的“匹配最小/最大角度”和“匹配最小/最大尺度”共用隔离匹配节点的运行参数，应用后提交，不另设一套测试参数。

例如运行搜索90°附近±5°，填写匹配最小角度85°、最大角度95°；缩放±10%填写最小尺度0.9、最大尺度1.1。上下限相同表示固定姿态。角度下限不能大于上限，跨度不超过360°；尺度须为0.1至10，下限不大于上限。搜索跨界角度可填写170°至190°。保存模型的制作范围必须覆盖运行区间；若模型仅制作约±20.05°，应先扩大制作范围、重新生成并应用，不能只改运行区间。HALCON NCC仅允许尺度1至1，尺度形状模型支持尺度区间。参考方向用于定义下游坐标系，不代替搜索角度。

HALCON直接把区间交给原生搜索，框架顺时针角度[a,b]转换为HALCON起始角度−b、跨度b−a，尺度使用min/max；不再循环固定角度/尺度。HALCON模型制作步长影响模型采样，运行端不使用OpenCV的采样步长。OpenCV灰度实现按“采样角度步长”“采样尺度步长”生成内部姿态，默认1°/0.01，两个端点始终参与搜索；最多4096组，并受比较预算约束。它的细化能力不同于HALCON，需根据精度与成本选择步长。

## 保存格式与引擎定制

制作掩膜沿用ROI绘制工具：包含区域取并集，再减去排除区域，孔洞保留。画布的“显示有效掩膜”以半透明绿色显示实际生效区域，属性列表的“制作掩膜”显示有效像素面积或错误；显示开关不修改模型。全部ROI禁用或有效区域为空时明确拒绝制作，不回退整图。试匹配显示实际搜索掩膜，独立于制作掩膜；更换测试图或测试条件会清除旧叠加。普通节点的复用方式见[掩膜创建、绑定与显示](vision-operators.md#掩膜创建绑定与显示)。

默认引用是配方相对路径：

```text
Resources/Templates/<模板ID>/revisions/<修订ID>/
  manifest.json
  source/image.bin
  source/mask.bin
  source/regions.xml
 variants/opencv-gray/model.bin
```

HALCON修订改用`variants/halcon/model.bin`，内容为SDK原生序列化的NCC或尺度形状模型，以`halcon.ncc.v1`/`halcon.scaled-shape.v1`区别格式。共同样图、精确有效掩码和参考定义仍保存，支持换引擎后重新制作。仅复制旧shm/ncm不能导入；原生模型需要兼容HALCON版本、运行环境与匹配许可。

共同清单记录格式版本、实现ID、模型格式、参考几何、制作参数、文件长度及SHA256。共同样图是有界的中立像素快照；区域XML复用已有带版本的ROI格式。OpenCV模型文件包含裁剪后的Gray8像素、有效掩码、平滑核和角度/尺度制作范围。

引擎通过 IVisionTemplateBuilder 生成自己的相对文件集合，以 ModelFormat 声明格式。文件数量、扩展名、内部格式由引擎决定，不强制厂商采用OpenCV二进制布局。制作入口、参数和显示方式由 IVisionTemplateFactoryDescription 提供；草稿试匹配通过 IVisionTemplatePreviewFactory 返回编辑器独立拥有的资源。

当前每个不可变修订对应一项匹配实现。不同引擎/方法的模型可以保留为同一模板身份下的不同修订，节点引用指定修订；没有“一个修订内任意切换全部引擎”的功能。需要重建的模型使用共同制作依据重新生成，不能把模型文件跨引擎复用。

节点保存资源引用及已确认参考定义。资源路径可以是绝对路径、已保存配方的相对路径或 resource: 引用。携带整个 Resources 目录移动配方后，相对引用继续可用。引擎插件和模板资源分开部署。

## 发布、取消和运行

- 模板制作作为挂载在匹配节点上的独立编辑模型，不是流程中每帧执行的节点。匹配节点保存稳定模板资源ID、指定版本引用及参考定义；制作模型由模板按钮创建隔离草稿，确认后回写。
- 节点窗口和模板弹窗分别使用隔离副本。未应用的制作期间保留内存草稿，直接取消不发布文件、不改正式节点。模板弹窗内点击过“应用”或确认后，再取消父窗口，会保留已发布但未引用的版本；正式节点保持原配置。
- 通用 PropertyGrid 增加 Action 编辑语义，以属性稳定键请求插件页面；共享UI不依赖Vision、HALCON或模型句柄。WinForms/WPF的工作室和节点详情窗口均支持这个入口。
- 通用节点编辑器增加 IWorkflowNodeEditorCommitParticipant，仅在应用时调用页面准备。模板页面先写入同目录草稿，再移动为完整新修订，随后提交节点引用。旧修订不覆盖。
- 写入失败或取消不更新节点引用。资源发布后如果节点提交失败，可能留下未引用版本；不自动删除。撤销/重做恢复引用，不删除其他节点可能使用的资源。本轮没有资源垃圾回收或旧修订删除界面。
- 模型制作及试匹配在后台进行。制作中应用被拒绝，过期完成结果不能覆盖已变化草稿。取消不能强制打断厂商原生调用，资源仍持有到调用结束。
- 打开节点或通用属性投影不读模型。用户点击模板按钮才读取当前资源清单、完整文件快照及样图，不初始化原生匹配模型。显式资源检查可以读取有界清单及文件元数据；真正准备会校验全部内容、格式和原生环境，创建模型。
- 根运行准备还检查节点确认的参考定义。定义不一致时以 ALG_TEMPLATE_REFERENCE_MISMATCH 阻断，发生在采集执行前，位置包含计划、节点和模型槽位。
- 下游节点已保存的ROI参考签名可以与上游资源节点确认的定义进行静态比较；版本或几何不一致在编译时报告，不必等到检测节点执行。
- 同内容、同参考定义和同制作配置的资源可以共享实例，修订路径不同不必重复创建模型。OpenCV声明共享串行，姿态模板缓存上限64MiB；最后租约和调用退出后释放。

## 坐标与兼容

资源模型的参考原点和方向属于样图几何。引擎返回裁剪模板到原图的姿态，结果据此给出参考点和参考方向（ReferenceX/Y、ReferenceAngleDegrees）以及参考到本帧图像的映射。模型内容签名与参考签名分开。

同一参考几何只改变制作参数或有效掩码、重新生成模型，不改变坐标语义。改变裁剪范围、原点、方向或样图内容会增加参考版本。替换样图即使尺寸相同也增加版本，要求下游重新确认。新模板的参考资源身份不同，也不能冒充原模板坐标。

模板匹配只输出位姿测量值，不产生坐标系。下游ROI/测量要随动时，用“构建本帧坐标系”的模板方式绑定匹配结果：坐标定义并入参考签名，参考变化后下游需重新确认。未找到目标时数值为NaN、构建停止，禁止沿用上一帧矩阵。

匹配结果的参考映射中，(0,0)表示参考原点：资源模板为制作时设置的参考原点，图像绑定模板为模板中心。不能把引擎裁剪模板的(0,0)当作业务原点。需要换算坐标时用“构建本帧坐标系”＋“点坐标系转换”。

OpenCV资源匹配按搜索区间和步长采样。整个区间必须在模型制作范围内，累计比较工作超预算明确报错。只支持平移的模型要求角度、尺度区间上下限相同，可以跟随搜索父坐标的旋转/尺度。

## 与旧 HALCON 项目的适配关系

旧 HBase_TemplateMatch.Cmd_ChangeTemplateModel 通过按钮调用 HTool_TemplateMatch，按 ModelID 找到独立 HTool_TemplateControl，不存在时创建，再请求展示。当前保留“按钮 → 独立制作模型 → 匹配节点引用”的交互，但使用配方资源身份及隔离草稿，不依赖全局 ToolMge、工具名或静态窗口。

旧代码根据 ShapeBasedMatching/GrayBasedMatching 调用 CreateScaledShapeModel/CreateNccModel，并分别保存 shm/ncm、样图和配置。现在HALCON自己的builder、参数描述、预览工厂和matcher已接入这些算子；通用制作窗口不持有HTuple，也不根据厂商名切换算子。旧HALCON文件不能直接当作当前清单导入，应使用样图及区域重新制作。

HALCON按节点角度/尺度区间调用原生搜索；跨越±180°时调用两段。实际姿态受原生模型采样及插值影响，结果报告原生值；金字塔细化可能使结果略超请求端点，范围不是最终结果的硬过滤。NCC分数是相关性，形状分数是轮廓匹配程度，不能与OpenCV平方差阈值直接比较。每段最多接受1024个检出，超过时失败；共同预算用于有效模板的ROI验证，不估算厂商内部金字塔运算。取消在原生调用边界生效，不保证中断单次SDK调用。

HALCON原点设为裁剪模板中心，原生返回的Row/Column按`affine_trans_pixel`语义转换到共同像素边界坐标，旋转/缩放时不是直接加0.5。完整有效模板必须落在搜索包含区域且不跨排除区域；不能只检查模型原点。共同参考原点/方向、后续坐标系和ROI沿用现有逻辑。
