# ADR-0010：以 DP.WorkFlow 建立独立重构主线

- 状态：Accepted
- 日期：2026-09-02

## 决策

从 `WorkFlow.Rebuild` 复制当前可运行基线到独立 `DP.WorkFlow` 目录。所有工作流程序集、项目路径和公共命名空间统一使用 `DP.WorkFlow` 前缀。旧目录只保留为对照基线，后续模型重构只进入新目录。

## 原因

在原目录中同时维持旧公开名称、兼容逻辑和新执行模型，会迫使每个结构调整承担双重语义。独立主线允许直接收紧编译不变量、执行身份和节点契约，同时仍可通过旧目录进行行为对照。

## 结果

这是公开程序集和命名空间的破坏性变更，使用方必须切换项目引用和 `using`。重构可以删除不再成立的兼容接口，但每个增量仍必须通过新解决方案的完整测试。
