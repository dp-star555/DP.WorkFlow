# ADR-0004：编译期并行作用域与运行时结构化并发

- 状态：Accepted
- 日期：2026-01-01

## 决策

`ParallelAll` 通过可多连线的 Branch 端口派发分支。Core 在编译期计算全部分支共同可达且距离最近的 `WaitAllInputsCompleted`，形成只读并行作用域。Runtime 并发执行各分支，所有分支到达汇聚点后只执行一次汇聚节点。

任一分支失败时取消同作用域内其他分支，并保留最先出现的原始失败；嵌套并行通过递归作用域执行。

## 原因

如果运行时临时猜测汇聚点，错误会延迟到设备执行期间；如果每条分支都执行汇聚节点，则汇聚后的动作会被重复执行。结构化作用域可以在设计期拒绝无汇聚并行，并为取消和快照提供明确边界。

## 结果

流程定义包含 `WorkflowParallelScopePlan`；快照包含活动节点集合和运行时作用域进度。当前上下文变量与节点输出仍共享，后续需要增加 Scope/Token 输出标识以处理同名并发输出。
