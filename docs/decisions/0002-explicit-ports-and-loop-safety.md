# ADR-0002：显式端口、连接基数和循环安全上限

- 状态：Accepted
- 日期：2026-01-01

## 决策

节点插件必须声明稳定输入/输出端口及最大连接数。节点执行只选择端口，由引擎解析目标节点。循环依赖图中的回边表达，每次运行同时受节点总执行次数和单节点执行次数限制。

## 原因

旧版节点直接读取出边字典并使用 `First()`，分支语义容易受集合顺序影响；错误 Jump 或 Loop 配置还可能形成无法停止的高速无限循环。

## 结果

设计期可以在运行前拒绝未知端口和超基数连接；循环仍可正常使用，但超过宿主配置的安全上限会以明确 Faulted 结果终止。
