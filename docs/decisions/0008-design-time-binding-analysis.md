# ADR-0008：设计期绑定可达性与类型分析

- 状态：Accepted
- 日期：2026-01-01

## 决策

节点目录可以声明标准输出 CLR 类型。Core 使用 `WorkflowBindingAnalyzer` 提取 `WorkflowInput<T>` 和节点显式声明的绑定，分析来源是否必然先于消费者完成，并校验成员路径与目标类型。

顺序和条件图使用支配节点分析；ParallelAll 汇聚后的可见性额外使用结构化并行作用域规则。Block 子输出映射针对子画布所有完成路径单独分析。

诊断代码为 WFB001 至 WFB005。默认编译会阻止确定错误；旧文档或 Runtime 防御测试可显式设置 `validateBindings: false`，但运行时解析保护始终保留。

## 原因

仅判断“来源节点可达”不能保证运行到消费者时来源已经执行，尤其是在条件分支和并行分支中。将错误延迟到设备运行阶段会造成不确定停机。

## 结果

设计器可以按消费者和目标类型获取绑定候选。动态 Action 输出因类型未知只产生 WFB003 警告；插件可通过 WorkflowNodeDescriptor.OutputType 提供完整分析能力。
