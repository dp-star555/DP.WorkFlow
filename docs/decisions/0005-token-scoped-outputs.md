# ADR-0005：按 Run、Token、Scope 和执行实例保存节点输出

- 状态：Accepted
- 日期：2026-01-01

## 决策

每条节点输出记录 `RunId`、`TokenId`、`ScopeIds`、节点执行次数和全局输出序号。绑定优先读取当前 Token，其次读取祖先 Token；兄弟分支输出在并行作用域完成前不可见，汇聚后才向父 Token 开放。

`TryGetNodeOutput(nodeId)` 仅保留给监视界面和旧版兼容，业务绑定必须使用带执行身份的解析器。

## 原因

单层 `{NodeId}.Result` 在循环和并行中会被覆盖，也允许尚未汇聚的兄弟分支互相读取，产生时序相关的偶发错误。

## 结果

Runtime 可以保留完整输出历史并提供确定性可见性；快照和 Trace 能标识活动 Token。后续持久化运行历史时可直接使用相同身份模型。
