# ADR-0003：不可变运行快照与可叠加 Hold

- 状态：Accepted
- 日期：2026-01-01

## 决策

运行引擎发布带 RunId 和单调 Sequence 的不可变快照。人工 Pause 与外部 Hold 分别记录；只有人工暂停已清除且全部 Hold 原因均被移除，调度门才重新打开。事件观察者异常不得改变流程结果。

## 原因

旧版 UI 需要自行处理快照乱序，单一暂停布尔值也无法区分人工暂停和多个设备条件。事件处理器异常若回传到引擎，会让显示层问题污染设备执行结果。

## 结果

WinForms、WPF 或远程监视器可以消费同一快照模型；Hold 可按原因去重和独立解除；快照和 Trace 均可安全跨线程传递。
