# Workflow 页面示例

不依赖 Foundation，直接打开 Workflow 的 5 个页面看效果：流程设计、运行、节点提示、运行日志、流程库。

## 运行

在 Visual Studio 里把 `DP.WorkFlow.Pages.Sample` 设为启动项目后 F5，或者命令行：

```
dotnet run --project samples/DP.WorkFlow.Pages.Sample
```

第一次运行会在程序目录的 `sample-data\flows` 下生成 3 条模拟流程（上料、检测、下料），都是“开始 → 循环 → 3 个模拟工位动作 → 回到循环”。
加 `--reset` 参数会清空 `sample-data` 重新生成。

## 可以看什么

- 顶部“全部启动”：3 条流程开始循环。上料、下料隔几圈会报一条“节拍提醒”，检测每 9 次拍照、下料每 14 次计数会失败一次。
- 运行页：左边流程列表（单独启停），中间指标和画布，有故障时右边自动切到“故障处理”，可以选“就地恢复”等去向。
- 节点提示页、运行日志页：上面这些提示和每一步的记录。
- 工具条“运行日志保存”：不保存（只在内存）/ 文本文件（`sample-data\runlogs\`，运行日志页才有“历史”）。
- 流程设计页：打开、改、保存草稿、发布；“调试运行”在单独的运行宿主里跑草稿（运行页有流程在跑时不能用）。
  右侧“节点属性”默认隐藏，点命令条上的按钮浮出，可以固定；底部页签默认收起成一条。
- 流程库页：新建、复制、改名、发布、版本历史。
- 顶部“主题”：5 套配色切换。

“模拟工位动作”节点在工具箱的“9.示例 / 模拟设备”里，动作时间、每隔几次提示、每隔几次失败都可以在节点属性里改。不连接任何设备。
